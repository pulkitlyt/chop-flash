# Chop Flash

Motorola-style "chop chop" flashlight for any Android phone (Android 8+).
Make two quick chopping motions to turn the flashlight on or off — even with the screen locked.

## Install

**[⬇ Download ChopFlash.apk](https://github.com/pulkitlyt/chop-flash/releases/latest/download/ChopFlash.apk)**

1. Open the link above on your phone.
2. Open the downloaded file. If asked, allow your browser to "install unknown apps".
3. Open **Chop Flash**, turn on **Enable**, and tap **Allow running in background**.

To update, download and install the latest APK again; your settings are kept.

## Tips

- **Not detecting chops?** Raise the sensitivity slider.
- **Turns on by itself while walking?** Lower it.
- **Stops working after a while?** On Xiaomi / Oppo / Vivo / Realme etc., also enable *Autostart* or set battery to *No restrictions* for Chop Flash.

## Building

Every push to `main` builds a signed APK with GitHub Actions and publishes it as a release.
Locally, open the project in Android Studio and press Run.
